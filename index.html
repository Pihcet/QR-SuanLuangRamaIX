สำรองข้อมูลขึ้น Google Drive ของคุณ

เชื่อมต่อบัญชี Google ของคุณเพื่อสำรอง QR Code ทั้งหมดไว้เป็นไฟล์ในไดรฟ์ส่วนตัวของคุณเอง แอปนี้ขอสิทธิ์แบบจำกัด (drive.file) จึงเข้าถึงได้เฉพาะไฟล์สำรองที่แอปสร้างขึ้นเท่านั้น ไม่สามารถเห็นไฟล์อื่นในไดรฟ์ของคุณ

การเชื่อมต่อ Google ต้องเปิดหน้านี้ผ่านที่อยู่เว็บ (http:// หรือ https://) เช่น อัปโหลดขึ้น GitHub Pages หรือรันเซิร์ฟเวอร์ในเครื่อง — หากเปิดไฟล์ตรงๆ (file://) จะเชื่อมต่อ Google ไม่ได้ หากยังไม่พร้อม ใช้ปุ่ม "ส่งออกเป็นไฟล์ JSON" ด้านล่างแทนได้ทันที

ยังไม่มี Client ID? สร้างได้ฟรีที่ Google Cloud Console → Credentials (สร้าง OAuth Client ID ประเภท "Web application" แล้วเพิ่มที่อยู่เว็บของคุณใน Authorized JavaScript origins)
